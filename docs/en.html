Senzhi AI (森智 AI) for e-commerce product photography

Senzhi AI is a workspace for creating product images from your own photos. A clothing store can start with a flat-lay photo of a cardigan, preview it on different models with virtual try-on, and prepare images for a product listing. For other products, use a reference photo to replace an item in a scene, create a white-background image, or draw attention to details such as a clasp or a stitched seam.

Turn a folder of photos into a batch

Suppose you want to see three cardigans on two models. Put the three garment photos in one source column and the two model photos in another. Choose All combinations to create six groups, one for each garment and model pairing. Preview the groups before submitting. A shared prompt such as “Dress the model in image 2 in the cardigan from image 1 and keep the pose” tells the tool how to use each photo.

For a shoot where each garment already has an assigned model photo, choose Pair in order. Arrange both columns so the photos on each row belong together. To use the same reference in every group, add it as a fixed image. In this mode, several fixed images rotate through the groups. You can also enable prompt optimization to adapt the shared instruction to the references in each group.

Review, download, or integrate

Open the image library to review recent results, select the shots you want, and download the originals together as a ZIP file.

For an integration, the API supports image, text, and video tasks. Use your account’s model list to see which models you can call and which parameters each accepts.

Guests can browse the workspace. Sign in to submit a task and check its estimated credit cost. Visit Senzhi AI · Open the workspace
